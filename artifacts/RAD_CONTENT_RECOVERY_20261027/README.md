# Recovered geographic source drafts

The historical taxonomy classified any URL containing “about” or «درباره» as an organization page. This incorrectly excluded a subset of complete articles about countries and cities. These files retain 49 recovered source articles as independent, unverified local drafts, with 1,242 original rich blocks in their original sequence and 49 original-link reference maps. Nothing here is published or represents an official legal verification.

The 41 `technically-ready-payloads` pass the closed CMS draft schema, have a single proposed country, match the current captured source body, blocks and links, and have original raw HTML bound by its recorded hash. The remaining eight require possible Visa-scope review. Even the 41 require human editorial and legal review; they are not publication-ready. Eight city-to-country proposals use the exact passages recorded in `country-evidence.json`; the rest are based on source title or URL. All remain proposals. Some independent articles may contain passages relevant to a main Visa page and must be reviewed before claiming complete country/category coverage.

The immutable originals remain in `RAD_CONTENT_CONSOLIDATION_20261026`. `source-observations.jsonl` records the current-source comparison; the raw captures are retained separately in the project audit directory and the historical raw caches. `dispositions.json` lists each source, proposed country, destination identity and blocking reason. Duplicate identities are blocked for review. No staging import has been performed as part of generating these files.

Reproduce with `python -m tools.content_completion.recover_geography`, passing the frozen corpus, the included source observations, `country-evidence.json`, `supabase/contracts/rad_v1.json`, the two hash-verified historical raw cache directories, and a new output directory. `scripts/tests/test_content_geography_delivery.py` independently checks all source blocks and reference bindings. A rollback-only local PostgreSQL rehearsal does not authorize hosted import.
