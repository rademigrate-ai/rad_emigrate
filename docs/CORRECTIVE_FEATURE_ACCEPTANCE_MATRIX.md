## Evidence and remaining boundary

- The deployed recovery and registration pages use the sign-in subtitle in both languages; the same references exist in this branch.
- Recovery catches every exception and sets `_sent = true`, falsely claiming a requested email after a transport failure. This is a confirmed code defect; a widget regression can reproduce the outcome without transmitting credentials or sending mail.
- Live recovery shows the previous wide institute logo. The current branch uses the owner's square emblem. Live `/version.json` returns only package/version metadata, whereas this branch's build script writes `git_sha` and Flutter version. The exact deployed SHA is therefore unverified; Render remains untouched.
- Browser semantic locator clicks did not activate Flutter canvas buttons in this session; supported CUA clicks did. Do not classify the tooling behavior as a product navigation defect.
- Protected routes, form persistence, real AI success, admin research interactions, mobile pixel checks and keyboard accessibility remain **not manually accepted** until secure authentication succeeds and the intended build is available.
