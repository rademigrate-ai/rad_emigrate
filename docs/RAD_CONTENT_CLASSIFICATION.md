# RAD Content Classification Taxonomy (Stage 3)

| Code | Meaning |
|------|---------|
| home | Site homepage |
| organization_about | About / identity |
| contact | Contact / location / phones |
| service | RAD service description |
| study_guidance | Study/education migration content |
| work_guidance | Work / skill migration content |
| investment_guidance | Investment / business migration |
| visa_visitor | Visitor/tourist visa content |
| medical_pathway | Medical professional pathways |
| immigration_guidance | General immigration methods |
| news_article | News / blog |
| legal | Privacy / terms |
| other | Unclassified relevant HTML page |

## Promotion policy

- `safe_first_party`: contact, about, home, service — may promote from current RAD evidence
- `review_required_regulatory`: study/work/investment/visa/medical/immigration — evidence only; no auto-approve as current law
