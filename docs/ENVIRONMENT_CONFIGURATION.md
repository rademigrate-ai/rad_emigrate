# Environment Configuration

## PUBLIC BUILD CONFIG
- SUPABASE_URL
- SUPABASE_PUBLISHABLE_KEY (or SUPABASE_ANON_KEY)
- APP_ENV

## SERVER SECRETS (never in Flutter)
- SUPABASE_SERVICE_ROLE_KEY
- AI provider API keys

## OWNER/EXTERNAL
- RAD_ANDROID_APPLICATION_ID
- RAD_RELEASE_STORE_FILE / PASSWORD / KEY_ALIAS / KEY_PASSWORD
- Apple Team ID / provisioning / certificates
