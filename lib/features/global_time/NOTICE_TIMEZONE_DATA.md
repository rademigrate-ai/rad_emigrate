# Timezone boundary data attribution

RAD Global Time uses geographic timezone boundary polygons from:

- **timezone_finder** (MIT code)
- Boundary data © OpenStreetMap contributors, available under the **Open Database License (ODbL)**
- Boundaries built by [Timezone Boundary Builder](https://github.com/evansiroky/timezone-boundary-builder)

Asset (Flutter Web):
`packages/timezone_finder/data/boundaries_2026c.bin`

Native platforms use the index embedded in the package and do not ship the extra 4 MB asset.
